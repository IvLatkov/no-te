colour scheme selects its white mark without modifying the artwork.

## Shortcut behaviour

Visual Studio Code retains its `vscode://` desktop link and manual launch fallback.
ChatGPT opens https://chatgpt.com/ in a new tab, alongside the unchanged Figma,
Cloudflare, GitHub and Supabase website shortcuts. All website links use
`rel="noopener noreferrer"`. No custom desktop launcher or environment flag is needed.
